ΚΕΝΤΡΟ ΠΡΟΓΡΑΜΜΑΤΙΣΜΟΥ — ΚΑΘΑΡΗ ΝΕΑ ΕΦΑΡΜΟΓΗ
Δοκιμαστική έκδοση 1.0.0-beta2, 12/10/2026

ΤΙ ΕΙΝΑΙ
Αυτόνομη προσωπική εφαρμογή Windows 64-bit με ελληνικό γραφικό περιβάλλον.
Ο κώδικας της εφαρμογής γράφτηκε από μηδενική βάση. Δεν περιέχει λειτουργίες σύνδεσης ή συγχρονισμού με διαδικτυακό αποθετήριο.

ΕΓΚΑΤΑΣΤΑΣΗ
1. Σε Windows 10/11 ανοίξτε το Kentro_Programmatismou_Setup.exe.
2. Επιλέξτε Ναι στην εγκατάσταση. Δεν απαιτούνται δικαιώματα διαχειριστή για τον προσωπικό λογαριασμό.
3. Ανοίξτε από την Επιφάνεια Εργασίας τη συντόμευση «Κέντρο Προγραμματισμού».
4. Στην εφαρμογή πατήστε «Εισαγωγή έργου ZIP» και επιλέξτε ΔΟΚΙΜΗ_ΕΡΓΟΥ_GO.zip.
5. Πατήστε «Ανάλυση έργου» και μετά «Εκτέλεση όλων των ελέγχων».
6. Ανοίξτε «Προβολή αποτελεσμάτων» ή «Εξαγωγή αναφοράς».

ΑΠΟΡΡΗΤΟ / ΑΣΦΑΛΕΙΑ
- Το Κέντρο δεν ανεβάζει από μόνο του έργα ή δεδομένα σε υπηρεσίες του διαδικτύου.
- Ο κώδικας των εισαγόμενων έργων ΕΚΤΕΛΕΙΤΑΙ πραγματικά. Εισαγάγετε μόνο αξιόπιστα πακέτα.
- Δεν υπάρχει πλήρης απομόνωση τύπου sandbox από κακόβουλο κώδικα.
- Η εξαγωγή αναφοράς εξαιρεί πηγαίο κώδικα και ακατέργαστα logs από προεπιλογή· ελέγξτε την πριν κοινοποιηθεί.
- Οι πηγές και τα αποτελέσματα αποθηκεύονται τοπικά στο %LOCALAPPDATA%\KentroProgrammatismou_Clean.
- Αν γίνει απεγκατάσταση με Uninstall.exe, διατηρούνται έργα, αναφορές και αντίγραφα.

ΑΠΑΙΤΟΥΜΕΝΑ ΕΡΓΑΛΕΙΑ ΓΙΑ ΑΛΛΑ ΕΡΓΑ
Η ίδια η εφαρμογή εκτελείται χωρίς Go ή Python εγκατεστημένα.
Για να κατασκευάσει και να δοκιμάσει έργα Go απαιτεί ήδη διαθέσιμο τοπικό Go compiler.
Για έργα Python απαιτεί Python και, για EXE, κατάλληλη συνταγή με τοπικό PyInstaller.
Όταν λείπει ένα εργαλείο, εμφανίζεται NOT RUN. Δεν εγκαθίστανται εξαρτήσεις από το internet.

ΠΕΡΙΟΡΙΣΜΟΙ ΒΗΤΑ
- Η εγκατάσταση, τα κουμπιά και η απεγκατάσταση ΔΕΝ έχουν δοκιμαστεί σε πραγματικό υπολογιστή Windows στην παρούσα παράδοση.
- Οι έλεγχοι stress υποστηρίζουν ρητά παραλληλία/επανάληψη και σενάριο αναγκαστικού τερματισμού με health check· δεν υποκαθιστούν εξειδικευμένες δοκιμές πραγματικών GUI πολλών χρηστών.
- Δεν υπάρχει πλήρης αυτόματη εγκατάσταση compiler ανά γλώσσα, διαχείριση isolation για μη έμπιστο κώδικα ή γενική μηχανή δημιουργίας Setup κάθε εισαγόμενου έργου.
- Γίνεται αυτόματη αναγνώριση βασικών Go tests και δοκιμών Python μέσα στον φάκελο tests/. Για ασφαλή κατασκευή EXE και εξειδικευμένα stress tests απαιτείται σωστό project-manifest.json.
- Για μεγάλα έργα μπορεί να απαιτούνται ειδικά σενάρια ελέγχου, απομόνωση εξαρτήσεων και εγκεκριμένος Windows δοκιμαστικός υπολογιστής.
- Η δοκιμαστική έκδοση δεν πρέπει να θεωρηθεί πιστοποιημένη τελική έκδοση παραγωγής.

ΑΠΕΓΚΑΤΑΣΤΑΣΗ
%LOCALAPPDATA%\Programs\KentroProgrammatismou_Clean\Uninstall.exe
Η προσωπική αποθήκη δεδομένων δεν διαγράφεται.

ΧΩΡΙΣ ΣΥΓΧΥΣΗ ΜΕ ΠΑΛΑΙΕΣ ΕΚΔΟΣΕΙΣ
Η νέα εφαρμογή έχει αποκλειστικά δική της βάση δεδομένων, δικό της φάκελο εγκατάστασης και δικό της πηγαίο κώδικα.
Δεν έγινε συγχώνευση με παλιές εκδόσεις. Δεν αφαιρέθηκαν προσωπικά παλιά αρχεία του χρήστη από Library/Drive.

ΤΙ ΑΛΛΑΞΕ ΑΠΟ ΤΗΝ beta1
- Επανασχεδιασμός ελληνικού dark native GUI, όχι web/browser.
- Απομονωμένος Windows chooser του ZIP: πιθανή αποτυχία δεν τερματίζει όλη την εφαρμογή.
- Προστέθηκε προστασία από panic GUI callback και crash.log.
- Βελτιώθηκε η αυτόματη αναγνώριση Python regression/stress scripts.
- Προστέθηκε Windows CI smoke test (για ξεχωριστό εξωτερικό GitHub repository).
- Αυτοματοποιημένο Windows smoke NOT RUN στο παρόν περιβάλλον.
