ΚΕΝΤΡΟ ΠΡΟΓΡΑΜΜΑΤΙΣΜΟΥ — ΤΕΧΝΙΚΗ ΑΝΑΦΟΡΑ ΕΚΔΟΣΗΣ 1.0.0-beta2
Ημερομηνία: 12/10/2026

ΔΙΟΡΘΩΣΗ ΑΣΤΟΧΙΑΣ
Η παλιά διαδικασία επιλογής ZIP χρησιμοποιούσε κοινό διάλογο Win32 στην κύρια διεργασία.
Ο διάλογος αντικαταστάθηκε από απομονωμένη διαδικασία Windows PowerShell/WinForms
που μπορεί να αποτύχει χωρίς να τερματιστεί η κύρια εφαρμογή. Προστέθηκε προστασία
και log όταν προκύπτει Go panic στην επεξεργασία γεγονότων GUI.
Η ακριβής αρχική αιτία crash ΔΕΝ έχει επιβεβαιωθεί με πραγματικό Windows dump.

ΓΡΑΦΙΚΟ
Αλλαγή διάταξης: σκούρο native Win32 GUI, έμφαση στην εισαγωγή ZIP,
στα έργα, στις ενέργειες και στα αποτελέσματα, μεγάλα χρωματιστά κουμπιά,
Segoe UI, καλύτερα περιθώρια, ελάχιστο μέγεθος παραθύρου.
Η οπτική απεικόνιση και συμπεριφορά σε πραγματικά Windows ΔΕΝ έχει ελεγχθεί.

ΕΛΕΓΧΟΙ ΠΟΥ ΕΚΤΕΛΕΣΤΗΚΑΝ ΠΡΑΓΜΑΤΙΚΑ ΣΕ LINUX/GO 1.23.2:
PASS: go test -count=1 ./...
PASS: go test -race -count=1 ./...
PASS: go vet ./...
PASS: GOOS=windows GOARCH=amd64 CGO_ENABLED=0 go build του GUI.
PASS: Windows EXE x64 τύπου PE32+ GUI.
PASS: GOOS=windows GOARCH=amd64 CGO_ENABLED=0 go build του Setup.
PASS: tests ZIP ασφαλείας, SHA256, ιστορικού, rollback, blocking gate.
PASS: έλεγχος αναγνώρισης Python regression/stress test scripts.

NOT RUN: πραγματική επιλογή ZIP/εισαγωγή μέσω UI σε Windows.
NOT RUN: Windows GitHub Actions — υπάρχουν αρχεία CI έτοιμα, δεν έγινε εκτέλεση.
NOT RUN: Windows screenshots/UI/manual usability testing.
NOT RUN: πλήρης εγκατάσταση/απεγκατάσταση σε πραγματικό Windows PC.
NOT RUN: εφαρμογή Python project 1.2.5 σε PC χωρίς/με εξαρτήσεις.

Η beta2 παραμένει ΔΟΚΙΜΑΣΤΙΚΗ. Δεν αντικαθιστά πιστοποιημένη σταθερή έκδοση.
Το GitHub ΔΕΝ ενσωματώνεται στην εφαρμογή. Τα CI scripts είναι αποκλειστικά
εξωτερικά και δεν τρέχουν στον υπολογιστή από το ίδιο το πρόγραμμα.
