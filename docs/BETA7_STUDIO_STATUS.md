# beta7 — Τοπικό Κέντρο Προγραμματισμού

## Ανασχεδιασμένη οθόνη Windows
- Φωτεινό περιβάλλον τύπου desktop studio, με σαφή τμήματα, λευκές κάρτες, νέα τυπογραφία και αριθμημένα στάδια.
- Τα κύρια βήματα είναι Εισαγωγή ZIP → Λειτουργικοί έλεγχοι / stress → αναφορά → EXE → προαιρετικό Setup.
- Η επιλεγμένη εργασία και το επιλεγμένο έργο διατηρούνται στη διάρκεια της χρήσης.
- Η παραγωγή EXE/Setup παραμένει κλειδωμένη μέχρι να περάσουν τα αντίστοιχα υποχρεωτικά τεστ.

## Ισχυρότεροι έλεγχοι
- Τα βασικά σενάρια parallel stress εκτελούνται τουλάχιστον 6 φορές, με έως τουλάχιστον 3 παράλληλες εργασίες. Τα σενάρια επανεκκίνησης εκτελούνται τουλάχιστον 4 φορές. Εάν το σχέδιο χρήστη προβλέπει πιο εντατική δοκιμή, αυτό διατηρείται.
- Αυτή η πολιτική προσφέρει πιο ισχυρή *ελάχιστη* δοκιμή. ΔΕΝ αποδεικνύει καθολική/εξαντλητική κάλυψη πραγματικών συνθηκών χωρίς ειδικά tests για το έργο.
- Η αναφορά καταγράφει πραγματικούς αριθμούς επαναλήψεων και παράλληλων εργασιών, και οι χρήστες βλέπουν το συγκεκριμένο σχέδιο ελέγχων πριν τρέξει.
- Αρχεία αναφορών με σαφή ονομασία: ΑΝΑΦΟΡΑ_ΕΛΕΓΧΟΙ_STRESS_ΟΝΟΜΑ_ΗΜΕΡΟΜΗΝΙΑ.zip αντί ακατανόητων αναγνωριστικών.

## Έλεγχοι πριν από παράδοση
- Windows unit/vet και πραγματικό Go GUI build + Setup.
- Windows end-to-end gate: λειτουργικοί έλεγχοι και stress → αναφορά → EXE/εκκίνηση → Setup.
- Native UI smoke: σωστή εμφάνιση κουμπιών, διαχωρισμός σταδίων, αρχικά κλειδωμένα EXE/Setup, ασφαλής επιλογή ZIP, screenshot πραγματικού runner.
- Ο χρήστης πρέπει να δοκιμάσει εμφάνιση και εγκατάσταση και στο δικό του Windows PC.
