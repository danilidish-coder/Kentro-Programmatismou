# Κέντρο Προγραμματισμού beta4 — έλεγχος πριν την παράδοση
- Τοπικό Windows GUI. Καμία σύνδεση με GitHub μέσα στην εφαρμογή.
- Νέα αναγνώριση αποδεδειγμένων συνταγών Python/PyInstaller από υπάρχοντα workflow του έργου ή μοναδικό spec.
- Δοκιμές εικόνας/τρεμοπαίγματος μόνο αφού ολοκληρωθούν build και έλεγχος εκκίνησης· έλεγχος του παραγόμενου JSON και όχι μόνο του exit code.
- Απλός έλεγχος απαιτούμενων τοπικών εργαλείων, χωρίς λήψεις.
- Πρόοδος και διάρκεια κατά τη δοκιμή, ευανάγνωστα αποτελέσματα με αυξητική ενημέρωση.
- Συνθετικό Windows Python/Tkinter EXE integration test, ενσωματωμένο στον υποχρεωτικό έλεγχο έκδοσης.
- Ο τελικός εγκαταστάτης θα δοθεί μόνο μετά από PASS σε πραγματικό Windows runner. Δεν υπάρχουν υπηρεσιακά δεδομένα στο repository.
- Εκκρεμεί πλήρης αισθητική αξιολόγηση χρήστη, αυτόνομη διαχείριση εκδόσεων εργαλείων και offline εγκατάσταση απαιτούμενων toolkits.
