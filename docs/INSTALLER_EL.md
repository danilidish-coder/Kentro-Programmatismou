# Installer v2.0.1 — Κέντρο Προγραμματισμού

Η εφαρμογή διατίθεται πλέον ως κανονική εγκατάσταση Windows (Inno Setup).
**Εγκατάσταση για τον τρέχοντα χρήστη, χωρίς δικαιώματα διαχειριστή**.

- Το Setup εγκαθιστά το μοναδικό αυτόνομο EXE (που περιέχει τα development tools) σε
  %LOCALAPPDATA%\Programs\Kentro_Programmatismou.
- Δημιουργεί συντόμευση «Κέντρο Προγραμματισμού» στην επιφάνεια εργασίας και στο μενού Έναρξη.
- Το σταθερό Inno AppId εξασφαλίζει ότι οι επόμενες εκδόσεις του installer εγκαθίστανται
  στον ίδιο φάκελο και **αντικαθιστούν** την εφαρμογή.
- Τα έργα, οι πηγές, το ιστορικό, τα τεστ, οι αναφορές και τα ενσωματωμένα εργαλεία
  βρίσκονται στο %LOCALAPPDATA%\KentroOfflineStudioV2, που **δεν διαγράφεται**
  κατά την εγκατάσταση, αναβάθμιση ή απεγκατάσταση.
- Αν χρησιμοποιούσε προηγουμένως **φορητό EXE** από Downloads/Desktop, αυτό **δεν
  είναι καταχωρημένη εγκατάσταση Windows**. Το Setup δεν διαγράφει άγνωστους
  προσωπικούς φακέλους ή παλιά EXE. Η νέα συντόμευση δείχνει πάντοτε στην εγκατεστημένη έκδοση.

## CI πιστοποίηση

Στο GitHub Windows runner:
1. Επαναλαμβάνονται όλοι οι έλεγχοι πραγματικής WPF λειτουργίας, bundled Python, Go, .NET και Node,
   ασφαλών ZIP, snapshot restore, approval gate, PyInstaller EXE και 16 συνδυασμών αντίθεσης καρτελών.
2. Δημιουργείται 1 setup EXE με Inno Setup σε fresh Windows session.
3. Γίνεται πραγματική εγκατάσταση, επιβεβαίωση ταυτόσημου SHA256 EXE,
   συντομεύσεων και πραγματική εκκίνηση παραθύρου.
4. Επαναλαμβάνεται η εγκατάσταση ως **αναβάθμιση**, ελέγχεται ότι δημιουργείται μία
   μόνο καταχώριση εφαρμογής.
5. Γίνεται κανονική απεγκατάσταση. Τα δεδομένα ενός πραγματικού τοπικού QA έργου
   ελέγχονται με SHA256 πριν και μετά, μαζί με τη διατήρηση όλων των φακέλων έργων.
6. Μόνο αν όλα επιτύχουν, δημοσιεύεται το Setup EXE ως ξεχωριστό GitHub prerelease.

Το Setup δεν πιστοποιεί λειτουργία σε κάθε πραγματικό PC/antivirus ή οποιοδήποτε τρίτο Python package
εκτός των ενσωματωμένων. Διατηρείται η προηγούμενη λειτουργική έκδοση στο ιστορικό GitHub.
