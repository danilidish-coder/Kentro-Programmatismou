# Δοκιμή Windows — beta3

Αναφορά αρχικής δοκιμής: το ZIP εισάγεται, αλλά όταν λείπει η γλώσσα Go στο τοπικό σύστημα, οι λειτουργικές δοκιμές και η κατασκευή δεν εκτελούνται. Οι δοκιμές φόρτου πρέπει να σημειώνονται **NOT RUN**, όχι αποτυχίες.

Η beta3 βελτιώνει την οθόνη με διαδοχικά αριθμημένα βήματα, κρύβει τις προχωρημένες λειτουργίες, διατηρεί σωστά τις αλλαγές γραμμής στις αναφορές και διορθώνει την κατηγοριοποίηση απουσίας εργαλείων.

Η διαθεσιμότητα compiler στον υπολογιστή του χρήστη παραμένει απαραίτητη. Δεν έχει υλοποιηθεί αυτόματη εγκατάσταση του Go. Κανένα απορρήτο έργο δεν ανεβαίνει στο δημόσιο αποθετήριο.

Απαιτείται νέος επιτυχής έλεγχος Windows GitHub Actions πριν διανεμηθεί το beta3 ως ελεγμένη έκδοση.
