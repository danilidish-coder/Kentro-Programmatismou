# Κέντρο Προγραμματισμού — νέο WinUI 3 Studio (υπό έλεγχο)

Το νέο ελληνικό γραφικό περιβάλλον είναι **κανονική εφαρμογή Windows** με native WinUI 3 / Fluent στοιχεία, αποχρώσεις, ανυψωμένες κάρτες και σκιές. Δεν χρησιμοποιεί browser και δεν επικοινωνεί με GitHub κατά τη χρήση.

## Αρχιτεκτονική

- `studio/`: αποκλειστικά γραφικό περιβάλλον C# / WinUI 3.
- `source/cmd/bridge/`: περιορισμένη **τοπική** διεπαφή JSON-lines προς την υπάρχουσα μηχανή Go.
- `source/engine/`: υπάρχων κώδικας ανάλυσης ZIP, unit/integration/stress, κατασκευής, έγκρισης EXE, αποθήκευσης αναφορών, SHA256. Δεν αλλάζει στην παρούσα μεταφορά.
- `source/gui*.go` και `source/theme_windows.go`: το παλιό Win32 GUI παραμένει ως βάση beta8 ώσπου να περάσουν πλήρως οι δοκιμές του νέου.

## Εγκατάσταση/παράδοση

Το Windows workflow κατασκευάζει και δημοσιεύει μόνο κατόπιν επιτυχίας το `Kentro_Programmatismou_Modern_Studio.zip`. Αποσυμπιέζουμε **ολόκληρο** τον φάκελο και εκτελούμε `Kentro_Programmatismou.exe`. Η εφαρμογή χρειάζεται τα συνημμένα DLL και το `Kentro_Engine.exe` που βρίσκονται στον ίδιο φάκελο. Δεν απαιτείται Python, Go, GitHub, browser ή Windows App SDK runtime εγκατεστημένο χωριστά για την εκτέλεση.

## Πού αποθηκεύονται τα εισαγόμενα προγράμματα

Τα ZIP που εισάγει ο χειριστής **δεν ανεβαίνουν στο GitHub**. Αποθηκεύονται τοπικά μέσα στο `%LOCALAPPDATA%\KentroProgrammatismou_Clean\projects\`. Η λίστα προγραμμάτων της εφαρμογής διαβάζει αυτό τον φάκελο. Το GitHub κρατά μόνο τον πηγαίο κώδικα και τις εκδόσεις **του ίδιου του Κέντρου Προγραμματισμού**.

## Έλεγχοι και περιορισμοί

Το παραγόμενο EXE δεν θεωρείται σταθερή έκδοση χωρίς Windows build, λειτουργικά/ενσωμάτωσης, πραγματικά GUI smoke και ελέγχους διανομής. Η αυτόματη δοκιμή παραθύρου δεν πιστοποιεί από μόνη της το αισθητικό αποτέλεσμα: χρειάζεται και πραγματική οπτική επιβεβαίωση από screenshot / χρήση.
