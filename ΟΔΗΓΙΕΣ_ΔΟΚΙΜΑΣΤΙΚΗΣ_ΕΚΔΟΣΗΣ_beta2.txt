ΚΕΝΤΡΟ ΠΡΟΓΡΑΜΜΑΤΙΣΜΟΥ — 1.0.0-beta2 (ΔΟΚΙΜΑΣΤΙΚΗ)

ΝΕΟ ΕΛΛΗΝΙΚΟ ΓΡΑΦΙΚΟ:
Σκούρα τεχνολογική διάταξη με περιοχές: Τα έργα μου / Εργασίες / Αποτελέσματα.
Το GitHub ΔΕΝ αποτελεί στοιχείο της εφαρμογής.

ΔΙΟΡΘΩΣΗ ΕΙΣΑΓΩΓΗΣ ZIP:
Ο διάλογος επιλέγεται πλέον από ανεξάρτητη διαδικασία Windows PowerShell.
Ακόμη και αν η διαδικασία αποτύχει, το κύριο πρόγραμμα πρέπει να μένει ανοιχτό
και να εμφανίζει μήνυμα σφάλματος. Δεν έχει επιβεβαιωθεί ακόμη σε πραγματικά Windows.

ΔΟΚΙΜΗ:
1. Κλείσε την προηγούμενη εφαρμογή.
2. Τρέξε το νέο Setup.exe.
3. Άνοιξε το Κέντρο Προγραμματισμού.
4. Πάτησε «ΕΙΣΑΓΩΓΗ ΕΡΓΟΥ ZIP».
5. Διάλεξε ένα αξιόπιστο ZIP. Μην εκτελέσεις δοκιμές σε άγνωστο κώδικα.
6. Έλεγξε αν η εφαρμογή παραμένει ανοιχτή.

ΑΝΑΦΟΡΑ ΣΦΑΛΜΑΤΟΣ: %LOCALAPPDATA%\KentroProgrammatismou_Clean\crash.log

Οι υποχρεωτικές δοκιμές του GitHub Actions περιλαμβάνονται στο πακέτο,
αλλά δεν έχουν ακόμη εκτελεστεί σε GitHub Windows runner.
Η beta2 ΔΕΝ είναι πιστοποιημένη σταθερή έκδοση.
