# Κέντρο Προγραμματισμού — Windows

Αυτόνομη εφαρμογή Windows για έλεγχο, δοκιμές, κατασκευή και τοπική διαχείριση προγραμμάτων, με ελληνικό γραφικό περιβάλλον.

**Κατάσταση:** `1.0.0-beta2` — δοκιμαστική έκδοση. Δεν έχει πιστοποιηθεί σε πραγματικό υπολογιστή Windows χρήστη. **Δεν περιλαμβάνει ενσωμάτωση GitHub.** Το GitHub χρησιμοποιείται μόνο εδώ για την ανάπτυξη και τις δοκιμές της ίδιας της εφαρμογής.

## Δομή

- `source/` — πλήρης πηγαίος κώδικας Go, ελληνικό Win32 GUI και μηχανή εκτέλεσης
- `installer/` — κώδικας εγκαταστάτη και εικονίδιο
- `ci/` και `.github/workflows/` — εξωτερικές αυτοματοποιημένες δοκιμές Windows και EXE
- `examples/` — μικρό μη ευαίσθητο δοκιμαστικό έργο
- `tests/` — διαθέσιμη αναφορά προηγούμενης δοκιμής, όχι πιστοποίηση του GitHub run

## Κατασκευή στα Windows

Προαπαιτούμενο Go 1.23 ή νεότερο. Εκτέλεση μέσα από τον φάκελο του αποθετηρίου:

```powershell
cd source
go test ./...
go vet ./...
go build -trimpath -ldflags '-H windowsgui -s -w' -o ../build/Kentro_Programmatismou.exe .
cd ..
Copy-Item build/Kentro_Programmatismou.exe installer/assets/Kentro_Programmatismou.exe -Force
$env:GO111MODULE='off'
go build -trimpath -ldflags '-H windowsgui -s -w' -o build/Kentro_Programmatismou_Setup.exe ./installer/setup_windows.go
```

Στο GitHub Actions η κατασκευή και οι έλεγχοι Windows γίνονται από το workflow `Windows validation and release candidate`. Τα EXE δίνονται ως artifacts μόνο εφόσον δημιουργηθούν. Πριν την πραγματική εγκατάσταση εξετάζουμε τα log και τα αποτελέσματα.

## Όρια / ασφάλεια

Δεν αποστέλλονται αυτόματα έργα, ρυθμίσεις ή δεδομένα σε GitHub ή άλλες υπηρεσίες. Η εισαγωγή ZIP εκτελείται τοπικά και ελέγχεται από τον κώδικα. Η δυνατότητα αυτοματοποιημένης αναγνώρισης/δοκιμής εξαρτάται από τα εργαλεία που υπάρχουν εγκατεστημένα και από την πραγματική δομή κάθε έργου. Μη χρησιμοποιείτε πραγματικά ευαίσθητα έργα στο δημόσιο αποθετήριο ή ως συνημμένα δοκιμών.
